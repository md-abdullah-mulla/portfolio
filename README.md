# Md Abdullah Mulla — Portfolio

Cinematic 3D developer portfolio.

**Live:** [https://md-abdullah-mulla.netlify.app](https://md-abdullah-mulla.netlify.app)

## Stack

React · Vite · Three.js / React Three Fiber · GSAP · Framer Motion · Tailwind CSS · Lenis

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Replace placeholders

Edit `src/utils/data.js`:

- `socials.email`
- `socials.phone`
- `socials.github`
- `socials.linkedin`
- `socials.facebook`
- each project's `github` and `live` URLs

Portrait: `public/images/portrait.webp` (fallback `portrait.jpg`).
